Extension Not Working at All

The extension icon is grayed out or nothing happens when clicked

Possible Causes & Solutions:

1
Extension is disabled

Fix: Go to chrome://extensions and make sure Canvas AI Assistant is enabled (toggle should be blue).

2
Browser needs restart

Fix: Close all Chrome windows completely and restart the browser. Sometimes extensions need a full restart to work properly.

3
Corrupted installation

Fix: Remove the extension from chrome://extensions and reinstall it.

4
Not on Canvas website

Fix: The extension only fully activates on Canvas (instructure.com) websites. Navigate to your school's Canvas page first.

🔐

Canvas Won't Connect

Token validation fails or connection shows error

Possible Causes & Solutions:

1
Invalid or expired token

Fix: Generate a new token in Canvas (Account → Settings → New Access Token) and update it in the extension settings.

2
Token copied incorrectly

Fix: Make sure you copied the entire token without extra spaces. Tokens are usually long strings of random characters.

3
School's Canvas URL not recognized

Fix: Make sure you're accessing Canvas through your school's official URL (e.g., yourschool.instructure.com).

4
Network/firewall blocking

Fix: Try on a different network (e.g., home WiFi vs school WiFi). Some school networks may block API requests.

🤖

Chatbot Not Appearing

Clicking "Open Chatbot" does nothing or shows error

Possible Causes & Solutions:

1
Not on a Canvas page

Fix: The chatbot only works on Canvas pages. Navigate to your school's Canvas site first (any page with instructure.com in the URL).

2
Page hasn't fully loaded

Fix: Wait for the Canvas page to fully load, then try again. You can also refresh the page (Cmd+R on Mac, Ctrl+R on Windows).

3
Content script not injected

Fix: Refresh the Canvas page. If that doesn't work, go to chrome://extensions, disable then re-enable the extension, and refresh Canvas again.

4
Chatbot is minimized

Fix: Look for a small circular icon in the corner of your screen. Click it to expand the chatbot.

🔄

Data Not Syncing

Courses, assignments, or grades not showing or outdated

Possible Causes & Solutions:

1
Haven't synced yet

Fix: Click the "Refresh Data" button in the extension popup, or reload any Canvas page to trigger a sync.

2
Token doesn't have proper permissions

Fix: Some schools restrict what data tokens can access. Try generating a new token and make sure you didn't limit its scope.

3
Cached data is stale

Fix: Go to Settings → Features → Click "Clear Cached Data", then refresh your Canvas page.

4
Auto-sync is disabled

Fix: Go to Settings → Features and enable "Automatically sync Canvas data".

💬

AI Not Responding Properly

Chatbot shows errors or gives generic responses

Possible Causes & Solutions:

1
No Canvas data available

Fix: The AI needs your Canvas data to give personalized responses. Make sure your Canvas token is connected and data has synced.

2
Network connectivity issue

Fix: Check your internet connection. The AI requires an internet connection to process requests.

3
Extension context invalidated

Fix: If you see "Extension Updated" message, simply refresh the Canvas page. This happens when the extension is updated or reloaded.

📅

Blackbaud Connection Issues

Can't connect or schedule not showing

Possible Causes & Solutions:

1
Wrong credentials

Fix: Use the same credentials you use for MySchoolApp. If you've forgotten them, contact your school's IT department.

2
School doesn't use Blackbaud

Fix: Blackbaud integration only works if your school uses Blackbaud/MySchoolApp. Check with your school if unsure.

3
Authorization popup blocked

Fix: Make sure your browser allows popups for the extension. Check for a blocked popup notification in the address bar.

🐌

Performance Issues

Extension is slow or Canvas pages load slowly

Possible Causes & Solutions:

1
Too much cached data

Fix: Go to Settings → Features → "Clear Cached Data" to reset the extension's stored data.

2
Many browser extensions running

Fix: Try disabling other extensions temporarily to see if performance improves. Too many extensions can slow down your browser.

3
Browser needs restart

Fix: Close and reopen Chrome. Browsers can slow down after running for a long time.

⏰

Token Expired

Extension suddenly stopped working after a period of time

Solution:

1
Generate a new token

If you set an expiration date on your token, you'll need to generate a new one:

  1. Go to Canvas → Account → Settings
  2. Find "Access Tokens" section
  3. Delete the old token
  4. Click "+ New Access Token"
  5. Set a new expiration date (or leave blank for no expiration)
  6. Copy the new token
  7. Update it in extension Settings → Authentication
💡
Tip: Consider setting your token to expire at the end of the school year, so you don't have to renew it frequently.

Still Having Issues?

If none of these solutions worked, please report your issue and we'll help you personally.
